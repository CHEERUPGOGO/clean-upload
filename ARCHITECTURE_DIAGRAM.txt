                            KEY STATISTICS

    L2 Tasks:
    • Parallel execution (all tools at once)
    • Tool count: 2-5
    • Candidate items: 3-6
    • Inline ID requirement: ≥2
    • Acceptance rate: ~25-30%

    L3 Tasks:
    • Sequential execution (tool chains)
    • Tool count: 2-5 (in chain)
    • Chain length: 2-6 steps
    • Candidate items: 10-30
    • Inline ID requirement: ≥3
    • Acceptance rate: ~20-25%

    Both:
    • Ambiguity levels: Low (40%), Moderate (40%), High (20%)
    • Ambiguity types: 5 (UNDERSPECIFICATION, SOFT_CONTRADICTION, etc.)
    • Multiple dataset support: Amazon, Yelp, Foursquare
